# Perler Studio 🎨

> 拼豆（Hama Beads / Perler Beads）像素图案工作室

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://redeyespk.github.io/perler-studio/)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

## 功能特性

### 🗂️ 库存管理
- 221 色拼豆颜色数据库
- 可视化色卡显示
- 库存筛选与搜索
- 库存分组统计

### 🎨 图案生成
- 9 种内置像素图案
- **上传图片 → 像素化转换**（新功能！）
- 可调节像素尺寸：16×16 / 24×24 / 32×32 / 48×48 / 64×64
- 颜色量化控制：4~64 色

### 📦 用量计算
- 图案所需各色数量统计
- 库存对比分析（缺色提醒）
- 采购清单生成
- 导出为 CSV/TXT

### 🖨️ 打印导出
- PNG 高清导出
- SVG 矢量导出
- 色号文本导出

## 使用方法

### 在线使用
直接访问：**https://redeyespk.github.io/perler-studio/**

### 本地运行
1. 下载 `perler-studio.html`
2. 用浏览器直接打开
3. 无需服务器，无需网络

### 上传图片生成图案
1. 切换到「图案生成」标签
2. 点击「上传图片」选择本地图片
3. 调整像素尺寸和颜色数量
4. 点击「转换」生成像素图
5. 预览效果，选择「设为图案」
